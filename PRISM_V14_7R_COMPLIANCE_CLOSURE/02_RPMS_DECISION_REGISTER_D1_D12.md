## Items for acknowledgement (not new decisions)

- **C-1 · Member formal submission has no Student UI.** The API accepts it (F01 proves it end to end), and the checklist tells members they "may … formally submit Adviser-approved project documents". The Student portal only shows a "Submit to RPMS" action to Admins, and its help text says "awaiting formal submission by RPMS". In current operation an Adviser approval submits automatically, so the gap affects only legacy "Ready for Formal RPMS Submission" versions; after the D12 cleanup none exist. Recommendation: acknowledge, and add the Student button if legacy approvals are ever retained. **Resolved by UX-01 (independent review):** the button now exists for exactly those versions, and the help text explains automatic Adviser forwarding.
- **C-2 · Adviser approval of a Final Report before Form 33 acceptance is refused** (HTTP 409, "RPMS acceptance is required for form33."). This is correct, but the message is technical. Recommendation: reword in a later UI pass.
